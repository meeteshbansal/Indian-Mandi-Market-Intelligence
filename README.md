# Indian Mandi Market Intelligence

An end-to-end data analytics project that explores Indian agricultural market prices to uncover insights into commodity pricing, market distribution, and price trends across different states and mandis.

## 📊 Project Overview

This project analyzes **737,392 agricultural market records** using Python, Excel, and Power BI to understand commodity price variations and market patterns.

## 🔍 Key Analysis

- **Data Cleaning:** Handled inconsistent state names, date formatting, and invalid price values.
- **Commodity Analysis:** Explored commodity frequency and variety distribution.
- **Market Analysis:** Compared market activity, grades, and price variations.
- **Price Analysis:** Examined minimum, maximum, and modal price distributions.
- **Trend Analysis:** Analyzed commodity price movements over time.
- **Dashboard Development:** Created interactive-style analytical dashboards in Excel and Power BI.

## 🛠️ Tools & Technologies

- **Python:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Microsoft Excel:** Dashboard and visual analysis
- **Power BI:** Interactive data visualization and reporting
- ** Google Colab:** Data cleaning and exploratory data analysis (EDA)
